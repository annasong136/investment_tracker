# Investment Tracker!

Hey there! This is just a fun personal project I've made to see a little bit of the code behind a investment tracking website. This is a personal investing platform designed to help users track portfolio performance, analyze transactions, and understand the thinking behind their investment decisions. Please note this is an educational project and must be used for personal use only!

Have fun, and feel free to reach out for bugs, improvements, or any thoughts at annasong136@gmail.com

## Features

- **Portfolio Tracking:** Record stock purchases and sales.
- **Performance Analytics:** Calculate realized/unrealized profit and loss, win rate, and trade performance.
- **Market Data:** Retrieve stock prices using Yahoo Finance.
- **Transaction Management:** Edit, save, and load portfolio data.

## Tech Stack
- Python
- Pandas
- yfinance
- CSV
- Google Colab

## Getting Started
You should have a Google Drive account, as the original application runs in Google Colab and uses Google Drive for portfolio storage.
